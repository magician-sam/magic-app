Magic wherever you are.

Add Magic by Sam to your phone or computer. Open the shows and your account from one easy icon.

Open Magic by Sam ↗

Windows computer

Use the live website as an app, with its own window and an icon in your Start menu. You do not need the blocked portable file.

  1. Open this page in Microsoft Edge.
  2. Choose ⋯ → More tools → Apps → Install this site as an app.
  3. Choose Install. You can then pin Magic by Sam to your taskbar.

Using Chrome? Choose ⋮ → Cast, save and share → Install page as app.

Open Backstage after installing ↗

Android

  1. Open this page in Chrome.
  2. Tap Chrome’s three-dot menu and choose Install app or Add to Home screen.
  3. Tap Install or Add.

iPhone

  1. Open this page in Safari.
  2. Tap Share (the square with an up arrow).
  3. Choose Add to Home Screen, then tap Add.

If you opened this link inside WhatsApp, use its menu to open it in Chrome or Safari first. The app needs internet for bookings and account details. No APK download, unsigned Windows program or change to your device’s security settings is needed.
